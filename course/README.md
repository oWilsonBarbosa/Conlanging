# Course Materials

This folder previously held 24 PDF lecture and assignment files for a
conlanging (constructed-language) course. **Those PDFs have been removed** because
they are third-party copyrighted materials and this repository should not
redistribute them.

These materials are the **Conlangs University** lessons, a free community
conlanging course. Please get them from — and credit — the original source:

- **Conlangs University — Lessons:** <https://sites.google.com/view/conlangs-university/lessons>

## Curriculum outline

The lessons followed this sequence:

1. Introduction to Conlanging
   - 1a. The Greatest Conlang Ever
2. Phonology 1 — *(+ assignment)*
3. Morphology 1 — *(+ assignment)*
4. Verbs 1 — *(+ assignment)*
5. Nouns 1 — Part 1: Case · Part 2: Number · Part 3: Class · Intro to Alignment *(+ assignment)*
6. Phonology 2 — *(+ assignment)*
7. Lexicon 1 — *(+ assignment)*
8. Documentation 1
9. Verbs 2
10. Phonology 3
11. Phonology 4 — *(+ assignment)*
12. Lexicon 2
13. Information Structure
