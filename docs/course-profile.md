## Why a proto-language changes the order of priorities

The course is written for a single synchronic conlang. Because the goal here is a
PIE-style ancestor, unit 11 (sound change) informs *every* earlier decision: the
phonology is deliberately seeded with diachronically productive material
(three-series stops, laryngeals, syllabic resonants, ablaut, mobile pitch accent)
so that daughters can diverge in interesting, naturalistic ways. See
`docs/design-goals.md`.
