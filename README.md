# Conlanging

Working through the *Course in Language Creation* (`course/`) to build a conlang
from scratch, one lesson at a time.

Method: each lesson's material is distilled into a document under `conlang/`,
followed by the decisions that lesson asks the conlanger to make. The guidance is
summarised from the course; the decisions are the author's.

## Repository

- `course/` — the course PDFs, lessons 01–13 with assignments
- `data/` — typological and lexical databases for checking features against real
  languages: WALS, Grambank, BDPROTO, CLTS, Concepticon, Phonotacticon,
  MorphoLex, MorphyNet, WOLD, Wiktextract
- `conlang/` — the conlang itself, one document per lesson
