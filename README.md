# Conlanging

Working through the *Course in Language Creation* (`course/`) to build a conlang
from scratch, one lesson at a time.

## The conlang

**Kelunta**, the lake tongue of the Keluri — a naturalistic, a priori,
agglutinative artlang for the lakeland of northwestern Meridia on Planet
#06cy8vf7zvurfgpbrgnm4l.

## Repository

- `course/` — the course PDFs, lessons 01–13 with assignments
- `data/` — typological and lexical databases used to check features against
  real languages: WALS, Grambank, BDPROTO, CLTS, Concepticon, Phonotacticon,
  MorphoLex, MorphyNet, WOLD, Wiktextract
- `conlang/` — the conlang itself, one document per lesson
