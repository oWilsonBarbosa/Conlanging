# Lesson 01 — Introduction to Conlanging

- **CU lesson:** <https://sites.google.com/view/conlangs-university/lessons> (Introduction; "The Greatest Conlang Ever")
- **Date:** 2026-06-14
- **Goal:** set Alantian's purpose and high-level aesthetic before any phonology.

## Decisions

- **Name:** **Alantian.**
- **Purpose / type:** **Artlang for worldbuilding** — the language of a fictional
  ancient culture; supports naming, inscriptions, and in-world texts.
- **Speakers / setting:** a **fictional people and world** (the Alantians). Register
  skews **classical / liturgical / elevated** — think a prestige or ceremonial language.
- **Aesthetic goals:** **ancient, elevated, moraic, resonant.**
  - *ancient / elevated* → a stately, archaic, "high register" feel.
  - *moraic* → the language is **mora-timed**; syllable weight is phonologically real.
  - *resonant* → sonorant-rich and vowel-heavy; smooth, ringing, open sound.
- **A-priori or a-posteriori:** **a-priori** — invented from scratch, not derived from
  any real language. Typological databases are used as **inspiration/plausibility
  checks only**, never as a lexical or structural source.
- **Scope for now:** a coherent **grammar sketch + starter lexicon**, built lesson by
  lesson through the CU curriculum.

## Aesthetic → design implications (to test in later lessons)

> Not decisions yet — hypotheses to validate against the databases in Lessons 02+.

- **Moraic** ⇒ expect **phonemic vowel length** and/or **geminate consonants**, a
  weight distinction (light vs. heavy syllables), and possibly **pitch accent**.
  Syllable structure likely simple: open syllables favored, e.g. (C)V(V)(C). → Lesson 02/06.
- **Resonant** ⇒ a **full sonorant series** (nasals m n ŋ, liquids l r, glides w j),
  vowel-heavy inventory, few or no harsh clusters; maybe nasal vowels. → Lesson 02.
- **Ancient/elevated** ⇒ favor "classical"-feeling phonemes, clean CV phonotactics,
  morphology that supports formal/poetic registers. → Lessons 03+.

## Rationale

A mora-timed, sonorant-heavy phonology with simple syllables produces the smooth,
"ringing", chant-like quality that reads as ancient and elevated (cf. the impression
many get from Latin, Sanskrit, or Hawaiian — used here only as a *feel* reference, not
a source). Worldbuilding scope keeps the project bounded and useful for the setting.
