# Design Journal

One log per [Conlangs University lesson](https://sites.google.com/view/conlangs-university/lessons).
Each records the goal, the decisions made, and **which databases/features informed
them** — so the strategy and sources are part of the repo, while the source data itself
stays external (see [`../../ATTRIBUTION.md`](../../ATTRIBUTION.md)).

Copy [`_template.md`](_template.md) for each new lesson.
