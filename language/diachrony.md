# Diachrony — Proto-Alantian → Alantian

> Alantian is built with an internal history: older ("Proto-Alantian", PA) forms plus
> **regular sound changes**. Much of the modern morphophonology — gemination, the ban on
> obstruent codas, the tense alternations — is the **residue** of these changes, not
> arbitrary synchronic rules.

## Prosody of the proto-stage (working assumption)

PA had **fixed initial stress** (e.g. *tápa-), which conditioned syncope. This feeds the
deferred suprasegmental decision (L10/11) — modern stress likely descends from it.

## Ordered sound changes

| # | Change | Statement |
|---|---|---|
| **S1** | Post-tonic syncope | An unstressed short vowel in an open, non-final syllable deletes: *CV́CV-CV → CV́C-CV. |
| **S2a** | Gemination | A coda stop + an identical onset → a geminate (p‑p → pp). |
| **S2b** | Place vocalization | A coda **obstruent** stop becomes a glide by place — **labial → u**, **velar → u**, **coronal → i** — forming a diphthong (or long vowel) with the preceding vowel. |

Sonorants {m n l r} and /s/ are **legal codas** and survive S2 unchanged. After S2 there
are **no obstruent codas left** — which is exactly the modern CV(R) constraint.

## Tense by reduplication

Tense is built by **reduplicating one edge** of the stem; the doubled syllable then
undergoes S1 (syncope), and the resulting cluster resolves by S2.

- **Non-past = final(rightward)-syllable reduplication** → a **medial geminate**.
- **Past = initial(leftward)-syllable reduplication** → an **initial cluster**
  (→ diphthong / geminate / legal coda, per S2).

```
stem *tápa-  "strike"
N.PST  (final redup)   *tápa-pa  ─S1→  *táppa             →  tappa
PST    (initial redup) *tá-tapa  ─S1→  *tátpa   ─S2b→  *táipa  →  taipa
```

### Across stem classes

| stem (C₁aC₂a) | N.PST — medial geminate | PST — initial cluster |
|---|---|---|
| *tapa* (t…p) | **tappa** | *tatpa* → **taipa** (t→i) |
| *mata* (m…t) | **matta** | **mamta** (m = legal coda) |
| *naka* (n…k) | **nakka** | **nanka** [naŋka] |
| *sapa* (s…p) | **sappa** | **saspa** (s = legal coda) |
| *kasa* (k…s) | **kassa** | *kaksa* → **kausa** (k→u) |
| *papa* (p…p) | **pappa** | **pappa** (p+p → geminate) |

So **non-past always shows a medial geminate**; **past shows the root's initial
consonant as a coda** — surfacing as a diphthong (obstruent → glide), a geminate
(identical), or a plain cluster (sonorant / s).

## What the modern grammar inherits (residue)

- **Geminates** exist because S2a fused C+C.
- **Obstruents are onset-only** because S2 vocalized/geminated away every obstruent coda.
- **Tense alternations** (tappa ~ taipa) are the fossilized output of reduplication + S1 + S2.
