# Diachrony — Proto-Alantian → Alantian

> Alantian is built with an internal history: older ("Proto-Alantian", PA) forms plus
> **regular sound changes**. Much of the modern morphophonology — gemination, the ban on
> obstruent codas, the tense alternations — is the **residue** of these changes, not
> arbitrary synchronic rules.

## Prosody of the proto-stage (working assumption)

PA had **fixed initial stress** (e.g. *tápa-), which conditioned syncope (below). This
feeds the deferred suprasegmental decision (L10/11) — modern stress is likely the
descendant of this.

## Ordered sound changes

| # | Change | Statement |
|---|---|---|
| **S1** | Post-tonic syncope | An unstressed short vowel in an open, non-final syllable deletes: *CV́CV-CV → CV́C-CV. |
| **S2a** | Gemination | A coda stop + an identical onset → a geminate (p-p → pp). |
| **S2b** | Labial vocalization | A coda **labial** stop → **/u/**, forming a diphthong with the preceding vowel (p-t → u-t). |
| **S2c** | _(pending)_ | Resolution of **non-labial** coda obstruents (coronal, velar; voiced; aspirate) before a stop — see Open. |

After S2 there are **no obstruent codas left**, which is exactly the modern CV(R)
constraint.

## Worked derivations — stem *tápa-* "to strike"

```
N.PST   *tápa-pa  ─S1→  *táppa            →  tappa
PST     *tápa-ta  ─S1→  *tápta  ─S2b→  *táuta   →  tauta
```

## What the modern grammar inherits (residue)

- **Geminates** exist because S2a fused C+C.
- **Obstruents are onset-only** because S2 vocalized/geminated away every obstruent coda.
- **Stem alternations in inflection** (*tappa ~ tauta*) are the fossilized output of S1+S2.

## Tense markers (PA)

- **Non-past** *-pa* · **Past** *-ta* (on an *-a* stem). Retires the earlier
  augment-prefix proposal — tense is **suffixal**, surfacing through S1+S2.

## Open

- **S2c:** how non-labial coda obstruents resolve (coronal/velar; voiced; aspirate).
- How the tense suffixes combine with the **aspect stems** (nasal infix / reduplication).
- Whether the synchronic **consonant gradation** should be re-derived from / reconciled
  with these changes.
